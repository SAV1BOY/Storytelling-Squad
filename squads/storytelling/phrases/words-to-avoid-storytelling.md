# Words and Phrases to Avoid in Storytelling

## Purpose
A reference list of words, phrases, and patterns that weaken narrative. Not banned —
context-dependent. But if you use them, know why, and have a better alternative ready.

---

## Corporate Jargon (Always Replace)

| Avoid | Replace With |
|-------|-------------|
| Utilize | Use |
| Facilitate | Help, enable, run |
| Leverage (verb) | Use, build on, apply |
| Synergy | Teamwork, alignment, combined effect |
| Ideate | Brainstorm, think through, explore |
| Paradigm | Model, approach, framework |
| Deliverables | What you get, the work, output |
| Bandwidth | Time, capacity |
| Circle back | Follow up, revisit |
| Move the needle | Make a difference, improve, change |
| Best-in-class | Leading, excellent, top-performing |
| World-class | Exceptional, excellent |
| Cutting-edge | Advanced, new, innovative |
| Game-changer | Breakthrough, shift, turning point |
| Disruptive | (Use only if genuinely disrupting a market) |
| Ecosystem | System, community, network |
| Holistic | Complete, full, comprehensive |
| Scalable | (Use only in technical contexts) |
| Robust | Strong, reliable, thorough |
| Deep dive | Close look, detailed analysis |
| Low-hanging fruit | Quick wins, easy improvements |
| Open the kimono | (Never use — just say "share" or "be transparent") |
| Boil the ocean | (Say "try to do everything at once") |
| Bleeding edge | (Say "extremely new" or "experimental") |

## Filler Words and Phrases (Delete)

| Delete This | Why |
|------------|-----|
| Very | Almost never adds meaning. "Very tired" → "exhausted." |
| Really | Same as "very." "Really important" → "critical." |
| Actually | Usually filler. Delete and re-read. |
| Basically | Signals you're about to oversimplify. Just say the thing. |
| Just | Minimizer. "I just wanted to…" → "I wanted to…" |
| Literally | Unless something literally happened. "I literally died" — no you didn't. |
| In order to | "To." Always just "to." |
| Due to the fact that | "Because." |
| At the end of the day | Delete entirely. |
| It goes without saying | Then don't say it. |
| Needless to say | See above. |
| It is important to note that | Just state the note. |
| It should be noted that | Just state it. |
| As a matter of fact | "In fact" or delete entirely. |
| For all intents and purposes | "Effectively" or delete. |
| At this point in time | "Now." |
| In the current climate | Name the specific condition. |

## Weak Verbs (Strengthen)

| Weak | Strong Alternatives |
|------|-------------------|
| Get | Earn, obtain, receive, achieve, gain, secure |
| Make | Build, create, craft, produce, forge, design |
| Do | Execute, perform, complete, tackle, accomplish |
| Have | Possess, hold, maintain, own, carry |
| Is/Are (static) | Rewrite with active verb: "The team is innovative" → "The team innovates" |
| Went | Traveled, drove, walked, sprinted, flew, marched |
| Said | (See dialogue-tags-and-beats.md for alternatives) |

## Hedge Words (Use Sparingly)

These words signal uncertainty. Sometimes appropriate (data caveats). Usually, they
just weaken your claim.

| Hedge | When to Keep | When to Cut |
|-------|-------------|-------------|
| Maybe | Genuine uncertainty | Opinion you believe in |
| Perhaps | Polite suggestion | Making a recommendation |
| Might | Honest possibility | Stating a proven outcome |
| Somewhat | Precise qualification | Vague filler |
| I think | Humble opinion | Expert recommendation |
| I feel like | Emotional honesty | Professional assertion |
| I believe | Values statement | Factual claim |
| Sort of / Kind of | Genuine approximation | Lazy precision |

## Empty Superlatives (Prove or Remove)

| Empty Claim | Better Approach |
|------------|-----------------|
| "The best" | Best by what measure? Say it. "Highest-rated by [source]." |
| "Amazing" | What specifically amazed? Show the reaction. |
| "Incredible" | Literally not credible. Show the evidence. |
| "Stunning" | What was the physical/emotional reaction? |
| "Revolutionary" | What did it replace? How is the new way fundamentally different? |
| "Unique" | Everything is unique. What specifically differentiates? |
| "Innovative" | What's the innovation? Name it. |
| "Passionate" | Show the passion through action, not declaration. |
| "Excited to announce" | Just announce. The excitement is in the thing. |

## Cliche Story Phrases (Find Fresh Versions)

| Cliche | Why It's Tired | Alternative Approach |
|--------|---------------|---------------------|
| "It was a dark and stormy night" | Literally a cliche origin example | Start with a specific, real detail |
| "Little did they know" | Overused foreshadowing | "What they didn't know —" or remove |
| "And the rest is history" | Lazy ending | Tell us what the "rest" actually was |
| "Against all odds" | Vague stakes | Name the specific odds |
| "Blood, sweat, and tears" | Dead metaphor | Describe the actual sacrifice |
| "Think outside the box" | Self-contradictory cliche | Describe the specific creative move |
| "Wearing many hats" | Dead metaphor | Name the actual roles |
| "Hit the ground running" | Overused | Describe what they actually did on day one |
| "At the end of the day" | Filler | Delete, or state the conclusion directly |
| "It is what it is" | Resignation dressed as wisdom | Name what it actually is and what to do |

## Patterns to Avoid

### 1. The Passive Deflector
"Mistakes were made." By whom? Say it: "I made a mistake" or "The team miscalculated."

### 2. The Complexity Shield
"The multifaceted, cross-functional synergies of our integrated platform ecosystem…"
Translation: "Our platform connects to other tools." Say that.

### 3. The Enthusiasm Mask
"We're thrilled to announce!!!" Let the announcement carry its own weight.

### 4. The Noun Pile-Up
"Customer experience optimization strategy implementation roadmap." That's six nouns
looking for a verb. Rewrite: "Here's how we'll improve the customer experience."

### 5. The Qualification Spiral
"I think it's possible that in some cases, certain approaches might potentially…" Commit to a claim or don't make one.

---

## The Test
Read your sentence aloud. If you wouldn't say it to a colleague in conversation,
rewrite it until you would.

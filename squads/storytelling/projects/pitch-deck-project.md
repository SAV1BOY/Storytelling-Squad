# Pitch Deck Narrative Project

## Purpose
Design the narrative structure and content for a pitch deck — investor, sales, or partnership.

---

## Project Overview
- **Duration:** 3-7 days
- **Agents:** Story Architect, Pitch Strategist (lead), Hook Specialist, Proof Curator
- **Deliverables:** Narrative script, slide-by-slide story notes, timing guide, delivery notes

---

## Phase 1: Brief and Strategy (Day 1)
- Define: audience, decision criteria, allotted time, competitive context
- Select framework: Duarte sparkline + Klaff frame control
- Determine story type: Founder Story (investors) or Value Story (sales)
- Calculate timing with pitch-timing-calculator

## Phase 2: Architecture (Day 2-3)
- Design sparkline contrast rhythm (what is / what could be alternation)
- Create beat sheet with slide-by-slide narrative notes
- Generate 3 hook alternatives, score with hook-strength-scorer
- Map emotional arc using emotion-mapping-rubric
- Identify proof blocks needed and sources

## Phase 3: Narrative Writing (Day 3-5)
- Write narrative script for each slide (speaker notes, not bullet points)
- Insert proof blocks at optimal positions
- Apply clarity linter to all text
- Design CTA using narrative CTA component

## Phase 4: Validation (Day 5-7)
- Score with pitch-scoring-rubric (target: 80+)
- Score with deck-scoring-rubric (target: 80+)
- Run deck-flow-analyzer for contrast and rhythm
- Time the full presentation — confirm buffer exists
- Prepare delivery coaching notes (pause points, emphasis, status dynamics)

---

## Success Criteria
- Pitch score: 80+
- Deck score: 80+
- Delivery time within allotment with 10% buffer
- Hook score: 70+
- At least 3 proof blocks integrated

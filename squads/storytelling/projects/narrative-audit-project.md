# Narrative Audit Project

## Purpose
Systematically evaluate all narrative assets across channels to identify strengths, gaps, inconsistencies, and improvement opportunities.

---

## Project Overview
- **Duration:** 1-2 weeks
- **Agents:** Narrative Analyst (lead), Brand Narrator, Story Bank Manager
- **Deliverables:** Audit report, gap analysis, improvement roadmap

---

## Phase 1: Asset Collection (Day 1-2)
Gather representative content from every active channel:
- Website: homepage, about page, product/service pages, blog (3 recent posts)
- Sales: pitch deck, proposal template, sales email sequences
- Marketing: 5 recent social posts, 3 recent emails, any active ads
- Internal: employee communications, onboarding materials
- Media: press releases, media kit

## Phase 2: Individual Assessment (Day 3-5)
Score each asset using appropriate rubrics:
- Run clarity-score-calculator on each piece
- Run story-structure-validator on narrative content
- Score 3-5 key assets with story-scoring-rubric
- Run proof-coverage-checker on claims-heavy content

## Phase 3: Cross-Channel Analysis (Day 5-7)
- Run narrative-consistency-checker across all collected assets
- Run brand-script-completeness-checker
- Complete story-bank-gap-detector analysis
- Identify contradictions, drift, and omissions

## Phase 4: Report and Roadmap (Day 7-10)
- Compile findings into audit report:
  - Executive summary
  - Per-channel assessment with scores
  - Cross-channel consistency score
  - Story bank coverage analysis
  - Top 5 strengths and top 5 gaps
- Create prioritized improvement roadmap:
  - Quick wins (fixable in 1 week)
  - Medium-term improvements (1-4 weeks)
  - Strategic initiatives (next quarter)

---

## Success Criteria
- All active channels assessed
- Scores calculated and documented
- Roadmap created with clear ownership and deadlines
- Stakeholders briefed on findings

# Value Shift Per Scene Audit
> Quality gate for verifying each scene shifts a value from positive to negative or vice versa with no neutral scenes

## Purpose
Ensure every scene in the narrative produces a measurable change in value charge. Scenes that begin and end at the same value are "neutral" and fail to move the story forward. This audit catches dead scenes before they bore the audience.

## Prerequisites
- Complete narrative draft with scenes numbered or labeled
- Genre's core value spectrum identified
- Each scene's beginning and ending emotional/dramatic state noted

## Checklist

### Value Identification
- [ ] **Core Value Named Per Scene** — Each scene has its primary value identified (e.g., life/death, truth/lie, freedom/oppression, love/hate, hope/despair)
- [ ] **Value Is Relevant to Genre** — The values shifting in most scenes connect to the global genre's value spectrum, not random or disconnected values
- [ ] **Values Are Specific** — Each value is named precisely, not vaguely; "things get worse" is not a value shift, "trust erodes to suspicion" is

### Shift Verification
- [ ] **Every Scene Has a Polarity Change** — Each scene moves from positive to negative (+ to -) or negative to positive (- to +) on its primary value
- [ ] **No Neutral Scenes** — No scene begins and ends at the same value charge; every scene changes something measurably
- [ ] **Shift Is Earned** — The value change results from character action, decision, or revelation within the scene, not from external convenience
- [ ] **Shift Is Perceptible** — A reader can feel the change without being told it happened; the shift is dramatized, not narrated

### Polarity Tracking
- [ ] **Polarity Map Created** — A scene-by-scene chart exists showing the value charge at the start and end of each scene (e.g., +, -, ++, --)
- [ ] **Alternating Pattern Present** — The polarity map shows variation; the story does not trend relentlessly in one direction without reversals
- [ ] **Escalation Visible** — The magnitude of shifts increases as the story progresses; late scenes shift more dramatically than early scenes
- [ ] **Double and Triple Shifts Tracked** — Scenes that shift through multiple values or shift more than once (reversal within a scene) are identified and used strategically

### Dead Scene Detection
- [ ] **Flat Scenes Identified** — Any scene where the beginning and ending values are identical has been flagged for revision or removal
- [ ] **Information-Only Scenes Converted** — Scenes that exist solely to deliver information have been given a value shift through conflict, discovery, or emotional change
- [ ] **Atmospheric Scenes Justified** — Any "mood" scene that remains has been verified to shift at least one value, even if subtly
- [ ] **Redundant Shifts Eliminated** — No two consecutive scenes shift the same value in the same direction without a reversal between them

### Global Pattern
- [ ] **Act-Level Shifts Clear** — Each act shows a net value shift that is distinct from the other acts
- [ ] **Global Shift Delivers Controlling Idea** — The overall movement from the first scene's value to the last scene's value embodies the controlling idea

## Scoring
| Rating | Criteria |
|--------|----------|
| Pass | All 17 items checked; every scene moves and the polarity map shows dynamic range |
| Conditional | 13-16 items checked; most scenes shift but 1-3 flat scenes remain |
| Fail | Fewer than 13 items, or more than 3 neutral scenes present |

## Next Steps
- Build the polarity map in a spreadsheet: Scene Number, Starting Value, Ending Value, Direction of Shift
- For flat scenes, add a complication, decision, or revelation that forces a value change
- If the polarity map trends in one direction too long, insert a reversal scene

# Data Storytelling Quality
> Quality gate for verifying data is contextualized, insight is clear, "so what" is answered, and action is implied

## Purpose
Ensure that data is presented within a narrative framework that gives it meaning. Raw data informs; data storytelling persuades. This audit checks that numbers are contextualized, insights are surfaced, implications are clear, and the audience knows what to do next.

## Prerequisites
- Data set or key metrics identified
- Audience's data literacy level assessed
- Narrative purpose for the data defined (persuade, inform, alarm, celebrate, decide)

## Checklist

### Data Contextualized
- [ ] **Baseline Provided** — Every metric is presented with a reference point (previous period, industry benchmark, target, competitor) so the audience knows if the number is good or bad
- [ ] **Scale Made Human** — Large or abstract numbers are translated into relatable terms ("enough to fill a football stadium," "one in every three households")
- [ ] **Trend Shown** — Data is presented as a trajectory (growing, declining, stable, volatile) not just a snapshot; the direction matters
- [ ] **Source Credible and Cited** — Data sources are identified and credible; the audience trusts the numbers

### Insight Clear
- [ ] **"So What" Answered** — For every data point, the narrative explicitly or clearly implies why this number matters to the audience
- [ ] **Insight Is One Sentence** — The core takeaway from the data can be expressed in a single, clear sentence; it is not buried in complexity
- [ ] **Causation vs. Correlation Respected** — The narrative does not imply causation from correlational data; claims match the evidence
- [ ] **Surprise Highlighted** — The most counterintuitive or unexpected finding is given prominence; data that confirms assumptions is deprioritized

### Narrative Structure
- [ ] **Data Embedded in Story** — Numbers appear within a narrative arc (situation, complication, resolution) not as a standalone data dump
- [ ] **Character or Protagonist Present** — The data is connected to a human experience: a customer, a team, a community whose story the data illustrates
- [ ] **Tension Created by Data** — The data reveals a problem, gap, or opportunity that creates narrative tension the audience wants resolved
- [ ] **Resolution Points to Action** — The data narrative concludes with an implication for what should happen next, not just what happened

### Action Implied
- [ ] **Decision Enabled** — The data storytelling gives the audience enough information and context to make a specific decision
- [ ] **Recommendation Clear** — If appropriate, the narrative explicitly recommends a course of action based on the data
- [ ] **Next Step Obvious** — The audience knows what to do with this information: investigate further, change strategy, invest, celebrate, or escalate
- [ ] **Data Supports the CTA** — If a call to action exists, the data directly supports it rather than existing separately

## Scoring
| Rating | Criteria |
|--------|----------|
| Pass | All 16 items checked; data is transformed into a compelling, actionable narrative |
| Conditional | 12-15 items checked; data is present and contextualized but insight or action is unclear |
| Fail | Fewer than 12 items, or data is presented without context, narrative, or actionable insight |

## Next Steps
- For every chart or metric, write one sentence starting with "This means..." to force the insight to the surface
- If the data is complex, lead with the headline insight and layer detail underneath for those who want it
- Test with a non-expert: can they state the key takeaway and the implied action after one reading?

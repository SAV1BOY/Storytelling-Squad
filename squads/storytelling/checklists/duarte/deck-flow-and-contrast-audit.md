# Deck Flow and Contrast Audit
> Quality gate for verifying contrast between sections, proof integration, visual rhythm, and breathing room in slide decks

## Purpose
Ensure the presentation deck flows as a cohesive visual and narrative experience with deliberate contrast between sections, evidence properly integrated, and enough visual breathing room to prevent cognitive overload.

## Prerequisites
- Complete slide deck drafted
- Presentation narrative or script written
- Audience context and venue/format known

## Checklist

### Section Contrast
- [ ] **Distinct Visual Sections** — The deck has identifiable sections (opening, problem, solution, proof, CTA) with visual cues (color shifts, divider slides, layout changes) marking transitions
- [ ] **Tonal Contrast Between Sections** — Adjacent sections differ in emotional tone (tension followed by relief, data followed by story, problem followed by possibility)
- [ ] **No Monotonous Stretches** — No run of more than 4-5 slides maintains the same visual style, tone, or content type without variation
- [ ] **Contrast Serves the Narrative** — Visual and tonal shifts align with narrative shifts, not arbitrary design choices

### Proof Integration
- [ ] **Evidence Supports Claims** — Every major claim in the deck is backed by data, testimonial, case study, or demonstration within 1-2 slides
- [ ] **Proof Is Visual** — Data is presented as charts, graphs, or images rather than text-heavy tables or bullet-point lists
- [ ] **Proof Is Contextual** — Numbers are given context (benchmarks, comparisons, before/after) so the audience knows whether to be impressed
- [ ] **Testimonials Are Specific** — Customer or stakeholder quotes include specific outcomes, not generic praise

### Visual Rhythm
- [ ] **Slides Breathe** — No slide is so packed with content that the audience cannot absorb it in the time allotted (generally 1 key idea per slide)
- [ ] **White Space Is Intentional** — Empty space on slides is used deliberately to direct attention, not filled with logos, footnotes, or decorative elements
- [ ] **Image-Heavy and Text-Heavy Alternate** — The deck alternates between visual slides and text slides, preventing visual fatigue
- [ ] **Consistent Design System** — Fonts, colors, and layout grids are consistent throughout, providing coherence even as content varies

### Pacing
- [ ] **Opening Hooks Immediately** — The first 2-3 slides grab attention through a provocative question, striking image, or surprising data point
- [ ] **Middle Maintains Energy** — The deck's middle section uses contrast and proof to sustain engagement, avoiding the "sag in the middle"
- [ ] **Closing Builds to Peak** — The final slides escalate to the most compelling content, not administrative details or Q&A placeholders
- [ ] **Slide Count Appropriate** — The total number of slides is appropriate for the allotted time (roughly 1-2 minutes per substantive slide)

## Scoring
| Rating | Criteria |
|--------|----------|
| Pass | All 16 items checked; the deck is a visually dynamic, narratively coherent experience |
| Conditional | 12-15 items checked; structure is sound but visual rhythm or proof integration needs work |
| Fail | Fewer than 12 items, or the deck is visually monotonous or overloaded |

## Next Steps
- Print all slides as thumbnails on a single page and assess visual rhythm at a glance
- If sections lack contrast, redesign section divider slides with distinct colors or full-bleed images
- If slides are overloaded, apply the "one idea per slide" rule and split dense slides
